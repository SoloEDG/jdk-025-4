# 遗迹探勘 Ruinfield

在数字与陷阱之间寻找失落文明的扫雷式探险游戏，并内置**关卡台**：为其他玩家制作、验证、试玩与分享自定义遗迹。

## 运行

```bash
npm install
npm run dev        # 本地开发
npm run typecheck  # 类型检查
npm run test:workshop  # 关卡台算法自测（16 项）
npm run build      # 生产构建
```

Docker：`docker compose up --build`，访问 http://localhost:18225。

## 关卡台（Level Workbench）

主导航切换到「关卡台」，完整工作流为：绘制 → 布置 → 验证 → 试玩 → 打包分享。

### 创作视图（作者可见全部答案）

- **不规则边界**：用「边界墙」画笔拖拽绘制任意形状遗迹，墙不参与探索。
- **陷阱 / 必经封门 / 文物 / 入口**：画笔布置；入口格受保护，需先迁移再覆盖。
- **起点与可用道具**：设置入口、生命数，以及探针 / 火把 / 护盾的配额（试玩与证明共用同一配额）。
- 陷阱一旦改动，**相邻数字、四连通区域、结构与验证结论立即重算**；不同连通区域以颜色区分。

### 试玩视图（只获得公开信息）

- 暗格的种类、文物、数字在揭开前完全不可见；推理高亮仅由已公开数字推出，不读取暗格答案。
- 探针给确定安全/危险结论；火把安全则揭开、危险仅确认；护盾抵挡一次陷阱。
- 每局试玩在开始时**锁定内容哈希**。作者随后修改关卡，进行中的旧试玩立即终止，
  已结算的旧版本成绩标记为「旧版本·不计成绩」，不能带着旧答案继续领成绩。

### 发布前验证（核心）

发布必须同时满足：

1. **结构校验**：每件目标文物都能从入口到达（墙只阻断连通，陷阱是可越过的危险格）；
   封门若非通往文物的必经之路会给出提醒；被墙完全包围、数字无法约束的陷阱也会提醒。
2. **无需猜测证明**：在给定道具下，存在一条完整探索路线，使每一步要么由公开数字必然推出安全，
   要么是「无公开约束的开局步」（等价于正式探险第一步），要么消耗道具取得确定信息——
   绝不依赖 50/50 猜测。

无法证明时，面板展示**卡在哪一组公开约束**：当时成立的数字方程、待决策前沿格、
未能到达的文物，以及已访问的信息状态数，帮助作者定位要补的道具或要改的布局。

### 搜索如何在状态等价、资源保留与证明完整性间平衡

朴素地穷举全部行动序列会重复遍历大量相同的信息状态，而贪心只点眼前安全格又可能浪费唯一道具。
求解器 `solver.ts` 采用三层设计：

- **宏闭包（确定性吸收）**：自动开门、揭开所有可证明安全格（含 0 数字洪水），
  把无需选择的进展一次性做完；搜索分支只发生在真正需要消耗资源的决策点。
- **状态等价去重 + 资源支配剪枝**：以「已揭示集 + 道具结论集 + 暴露陷阱集 + 资源向量」
  规范化信息状态做去重；信息相同但某状态每种道具与生命都不劣时，丢弃被支配的状态。
- **资源保留的分支策略**：卡住时按「探针 → 火把 → 护盾」排序，每类工具每状态只对
  信息量最高（被最多方程引用）的一个目标展开，避免把有限探针摊到多格；
  配节点预算（默认 6000）与墙钟预算（默认 4s）双上限，超限返回 `cap` 并附取证，UI 不卡死。

信念求解 `belief.ts` 是一个只消费公开观测的 0/1 CSP：枚举数字方程变量的一致陷阱配置，
在所有配置中恒安全/恒危险的格才给出确定结论；带访问预算与模型上限，超限时保守降级，绝不臆断。

### 分享与导入

- 发布生成 `RF1:` 开头、带校验和的 URL 安全分享码，关卡内容与**随包证明**一起打包。
- 只有 `verdict=proved` 且证明的内容哈希与当前内容一致的证明才能随关卡发布。
- 导入时**先校验再试玩**：结构非法直接拒绝；证明哈希不符则丢弃证明（可试玩，但需重新验证才能发布）。
- 任何编辑都会改变内容哈希，使旧证明、旧发布版本失效，从机制上杜绝「改了陷阱还用旧证明发布」。

## 目录

```
src/
  shared/level.ts                 关卡/证明/分享包数据模型
  features/workshop/
    model/
      geometry.ts                 邻接数字、连通、洪水、内容哈希
      regions.ts                  四连通区域标注
      validate.ts                 结构校验（可达性、封门必要性等）
      belief.ts                   公开信息 CSP 信念求解
      solver.ts                   无猜证明搜索（闭包/等价/支配/预算）
      play.ts                     试玩引擎（公开信息隔离）
      codec.ts                    打包、分享码编解码、导入校验
      editor.ts / store.ts / useWorkshop.ts
    ui/                           创作视图、试玩视图、验证/分享面板
  workshop.selftest.ts            算法自测（不参与应用构建）
```
